# Plan 02-01: state.py Extraction + main.py Refactor

## Objective

Extract `price_cache` and `market_source` singletons from `main.py` into a new `backend/app/state.py` module, and create the `backend/app/api/` package skeleton. This is the required foundation — Wave 2 plans (portfolio and watchlist routes) import their shared state from `app.state`.

Purpose: Eliminate circular import risk and enable Wave 2 route files to share the same `price_cache` and `market_source` instances without passing them through function arguments or FastAPI dependency injection overhead.

Output: `backend/app/state.py`, `backend/app/api/__init__.py`, refactored `backend/app/main.py`, and a passing test that verifies state exports are importable and the app still starts.
