Create `backend/app/api/portfolio.py`. This file owns: the portfolio router, three route handlers, and the `record_portfolio_snapshot` function.

**Imports needed:**
```
import asyncio, sqlite3, uuid
from datetime import datetime, timezone
from fastapi import APIRouter, HTTPException
from pydantic import BaseModel
from app.db import get_db_path
from app.state import price_cache
```

**Pydantic models (flat, minimal per CONTEXT.md specifics):**
- `TradeRequest`: fields `ticker: str`, `quantity: float`, `side: str` (values "buy" or "sell")
- No response models needed — return plain dicts.

**`record_portfolio_snapshot(db_path, cache)` function (per D-08):**
- Opens `sqlite3.connect(db_path)` with context manager.
- Reads all positions: `SELECT ticker, quantity, avg_cost FROM positions WHERE user_id='default'`.
- Reads cash: `SELECT cash_balance FROM users_profile WHERE id='default'`.
- For each position: `price = cache.get_price(ticker)`, falls back to `avg_cost` if None.
- Computes `total_value = cash + sum(quantity * price for each position)`.
- Inserts row: `INSERT INTO portfolio_snapshots (id, user_id, total_value, recorded_at) VALUES (...)`.

**`GET /portfolio` handler (API-01):**
- Opens DB, reads positions and cash in one connection.
- Calls `price_cache.get_all()` to get current prices.
- For each position row: compute `current_price` (from cache, fallback to `avg_cost`), `unrealized_pnl = (current_price - avg_cost) * quantity`, `pnl_percent = (current_price - avg_cost) / avg_cost * 100` (guard for avg_cost=0).
- Returns `{"positions": [...], "cash_balance": cash, "total_value": cash + sum(position_values)}`.

**`POST /portfolio/trade` handler (API-02, TRADE-01–05):**
- Reads `price = price_cache.get_price(ticker)` — if None, raise `HTTPException(503, detail=f"Price unavailable for {ticker}")` per D-13.
- Opens a single DB connection (all reads and writes in one `with` block for atomicity per Pattern 6 in RESEARCH.md).
- Reads `cash_balance` from `users_profile`.
- **Buy path (per D-11):**
  - Validate: `cash_balance >= quantity * price`, else raise `HTTPException(400, detail=f"Insufficient cash: need ${quantity*price:.2f}, have ${cash_balance:.2f}")` per D-07.
  - Read existing position row.
  - If row exists: compute weighted avg_cost, UPDATE positions.
  - If no row: INSERT into positions.
  - Deduct cash: `UPDATE users_profile SET cash_balance=? WHERE id='default'`.
  - Append to trades table.
- **Sell path (per D-12):**
  - Read existing position — if none or quantity < sell_qty, raise `HTTPException(400, detail=f"Insufficient shares: have {existing_qty:.4g}, selling {quantity:.4g}")` per D-07.
  - Compute new_qty = existing_qty - quantity.
  - If `new_qty <= 1e-9`: DELETE the positions row (per D-12 and RESEARCH.md Pitfall 5).
  - Else: UPDATE positions SET quantity=new_qty.
  - Add cash: UPDATE users_profile.
  - Append to trades table.
- After the DB transaction, call `record_portfolio_snapshot(get_db_path(), price_cache)` directly (per D-10).
- Return `{"status": "ok", "ticker": ticker, "side": side, "quantity": quantity, "price": price}`.

**`GET /portfolio/history` handler (API-03):**
- Simple SELECT: `SELECT total_value, recorded_at FROM portfolio_snapshots WHERE user_id='default' ORDER BY recorded_at ASC`.
- Return `{"history": [{"total_value": ..., "recorded_at": ...}, ...]}`.


```
async def snapshot_loop():
    while True:
        try:
            record_portfolio_snapshot(get_db_path(), state.price_cache)
        except Exception:
            logger.exception("Snapshot failed")
        await asyncio.sleep(30)
```
3. In lifespan startup (after `await state.market_source.start(...)`):
```
state.snapshot_task = asyncio.create_task(snapshot_loop(), name="snapshot-loop")
```

4. In lifespan shutdown (before or after `await state.market_source.stop()`):
```
if state.snapshot_task and not state.snapshot_task.done():
    state.snapshot_task.cancel()
    try:
        await state.snapshot_task
    except asyncio.CancelledError:
        pass
```
