Create Dockerfile at the project root with exactly two stages:

STAGE 1 — Node build:
  Base image: node:20-slim
  WORKDIR /build
  Copy frontend/ into /build/frontend/
  RUN npm ci --prefix frontend
  RUN npm run build --prefix frontend
  This produces /build/frontend/out/ with the static export.

STAGE 2 — Python runtime:
  Base image: python:3.12-slim
  Install uv via pip (pip install uv) — simplest approach, no curl needed in slim image.
  WORKDIR /app
  Copy backend/ into /app/backend/
  RUN cd /app/backend && uv sync --no-dev
    (--no-dev excludes pytest/ruff/httpx from the production image)
  Copy frontend out from Stage 1: COPY --from=0 /build/frontend/out /app/static
  Create db directory: RUN mkdir -p /app/db
  EXPOSE 8000
  WORKDIR /app/backend
  CMD ["uv", "run", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]

Important details:
- The .env file is NOT copied into the image. It is passed at runtime via --env-file.
- The db/ directory at /app/db is the volume mount point. mkdir -p ensures it exists even without a volume.
- Use COPY backend/ /app/backend/ (trailing slash = directory contents go inside)
- Use COPY frontend/ /build/frontend/ similarly
- Do NOT add a .dockerignore yet (addressed in Plan 02 via scripts context); the build context is the project root.
- uv sync reads backend/uv.lock (the lockfile committed to the repo). Confirm uv.lock exists at backend/uv.lock — if it does not exist, the build will fail and Plan 02 must add a note; however it should exist since backend was already developed with uv.

   STATIC_DIR = Path("/app/static")

3. After all app.include_router() calls and after the /api/health route, add the static file mount and catch-all. The ORDER is critical — API routes must be registered first:

   # Serve static files only when the directory exists (production/Docker)
   if STATIC_DIR.exists():
       app.mount("/", StaticFiles(directory=STATIC_DIR, html=True), name="static")

4. The html=True parameter on StaticFiles makes FastAPI automatically serve index.html for directory requests (e.g., GET / returns /app/static/index.html).

5. For SPA routing (any client-side route like /portfolio, /chat that does not exist as a file): StaticFiles with html=True already handles 404s by falling back to index.html when the path doesn't match a file. This covers SPA routing without a separate catch-all route.

6. The STATIC_DIR.exists() guard means the backend still works in development mode (when running locally via uvicorn without the static files — the frontend runs on port 3000 with the Next.js dev server).

7. Do NOT remove or change the CORSMiddleware — it is still needed for local development.

8. Do NOT change the load_dotenv() call — it already resolves correctly to the project root in both local dev and Docker contexts.
