    Create frontend/src/lib/store.ts using Zustand (per D-07):

    Define PriceUpdate interface with fields: ticker, price, previous_price, timestamp, change, change_percent, direction ('up'|'down'|'flat').

    Define PriceStore interface:
    - `prices: Record<string, PriceUpdate>` — keyed by ticker
    - `status: 'CONNECTING' | 'OPEN' | 'CLOSED'`
    - `setPrices(updates: Record<string, PriceUpdate>): void` — merges into existing prices (Object.assign or spread, not replace)
    - `setStatus(status: PriceStore['status']): void`

    Create the store with `create<PriceStore>()((set) => ({ ... }))`.

    Export: `export const usePriceStore = ...` (named export, not default).

    Create frontend/src/hooks/useSSE.ts (per D-09):

    `useSSE()` is a React hook called once at the app root (in layout.tsx or page.tsx). It:
    1. Creates a single `EventSource` instance on mount at `/api/stream/prices`
    2. Sets status to 'CONNECTING' immediately
    3. On `source.onopen`: calls `usePriceStore.getState().setStatus('OPEN')`
    4. On `source.onmessage`: parses `event.data` as `Record<string, PriceUpdate>`, calls `usePriceStore.getState().setPrices(parsed)` — use try/catch; log parse errors to console.error, do not throw
    5. On `source.onerror`: calls `usePriceStore.getState().setStatus('CLOSED')` — EventSource has built-in retry, so do not call source.close()
    6. Returns cleanup function that calls `source.close()` from the useEffect cleanup

    Important: import `usePriceStore` from `'@/lib/store'` (not relative path). The hook accesses the store via `usePriceStore.getState()` inside event handlers (not via the hook — avoids re-render inside a closure).

    Do not add sparkline history or any additional state to the store in this plan — sparkline accumulation is handled in the Watchlist component (Plan 02).
  </action>
