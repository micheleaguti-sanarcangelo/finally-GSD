    Create frontend/src/components/TradeBar.tsx as a client component.

    Props interface:
    ```
    interface TradeBarProps {
      selectedTicker: string | null;
      onTradeExecuted: () => void;  // called after successful trade so parent re-fetches portfolio
    }
    ```

    State:
    - `ticker: string` — pre-filled from selectedTicker prop, also user-editable
    - `quantity: string` — raw input string (validated before submit)
    - `loading: boolean` — true while POST is in flight
    - `error: string | null` — error message from API (insufficient cash, etc.)

    Sync selectedTicker prop to ticker state: use `useEffect` on `selectedTicker` — when it changes and is not null, call `setTicker(selectedTicker)`.

    On buy/sell button click:
    1. Parse quantity as integer: `const qty = parseInt(quantity, 10)`; if NaN or <= 0, set error "Invalid quantity" and return
    2. Set loading true, clear error
    3. `fetch('/api/portfolio/trade', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({ ticker: ticker.toUpperCase().trim(), quantity: qty, side }) })`
    4. If response.ok: clear error, call `onTradeExecuted()`, do NOT clear the ticker/quantity fields (user likely wants to trade again)
    5. If response status 400: parse `{ detail }` from response JSON, set error to detail string
    6. If network error: set error "Network error — is the backend running?"
    7. Set loading false in finally block

    Layout: compact horizontal bar or vertical stack (discretion). Styling:
    - Ticker input: `background: #1a1a2e`, `color: #e2e8f0`, `border: 1px solid #2a2a3a`, uppercase text
    - Quantity input: same styling, type="number" min="1" step="1"
    - Buy button: `background-color: #22c55e` (green), bold text, hover darken
    - Sell button: `background-color: #ef4444` (red), bold text, hover darken
    - Error message: text-red-400, text-xs, below the inputs
    - Loading state: buttons show "..." text, disabled

    Submit buttons must be disabled when loading is true to prevent double-submission.

    Export: `export function TradeBar({ selectedTicker, onTradeExecuted }: TradeBarProps)`
  </action>

    Create frontend/src/components/PositionsTable.tsx as a client component.

    Props interface:
    ```
    interface PositionsTableProps {
      positions: Array<{
        ticker: string;
        quantity: number;
        avg_cost: number;
        unrealized_pnl: number;
        pnl_percent: number;
      }>;
    }
    ```

    The component reads live prices from Zustand for the "Current Price" column (per D-07/D-12):
    - `const prices = usePriceStore(state => state.prices)`
    - For each position, use `prices[position.ticker]?.price ?? position.avg_cost` as the displayed current price
    - Recompute unrealized P&L display from live price: `livePrice - avg_cost) * quantity` — do not use the `unrealized_pnl` from the prop (which is stale from the last REST fetch)
    - Recompute pnl_percent similarly: `((livePrice - avg_cost) / avg_cost) * 100`

    Table columns: Ticker | Qty | Avg Cost | Live Price | P&L ($) | P&L (%)
    - Ticker: bold, accent-yellow text
    - Qty: right-aligned, monospace
    - Avg Cost: right-aligned, `$X.XX` format
    - Live Price: right-aligned, monospace
    - P&L ($): green if positive, red if negative
    - P&L (%): green if positive, red if negative, formatted as `+X.XX%` or `-X.XX%`

    If positions array is empty, show a single row with centered text: "No positions — buy something from the trade bar".

    Styling: same dark table as WatchlistPanel — `bg-[#0d1117]`, thin gray borders, text-xs/text-sm, no outer border.

    Export: `export function PositionsTable({ positions }: PositionsTableProps)`

    ---

    Create frontend/src/components/ChatPanel.tsx as a client component.

    Props interface:
    ```
    interface ChatPanelProps {
      onTradeExecuted: () => void;  // called after assistant executes trades (re-fetch portfolio)
    }
    ```

    State:
    - `messages: ChatMessage[]` where `ChatMessage = { role: 'user' | 'assistant'; content: string; trades?: Array<{ticker, side, quantity}>; watchlist_changes?: Array<{ticker, action}> }`
    - `input: string`
    - `loading: boolean`

    On mount: no history fetch needed — start with empty messages array (per spec: fresh session).

    On send (button click or Enter key in textarea):
    1. If input is empty or loading, return
    2. Append user message to messages: `{ role: 'user', content: input }`
    3. Clear input, set loading true
    4. `fetch('/api/chat', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({ message: input }) })`
    5. On success: parse ChatResponse, append assistant message: `{ role: 'assistant', content: data.message, trades: data.trades, watchlist_changes: data.watchlist_changes }`
    6. If data.trades.length > 0: call `onTradeExecuted()` (triggers portfolio re-fetch)
    7. On error: append assistant message with content "Error: could not reach the assistant. Try again."
    8. Set loading false

    Rendering messages:
    - User messages: right-aligned bubble, `background: #1e2a3a`, text-white
    - Assistant messages: left-aligned bubble, `background: #0f1923`, text-gray-200
    - After assistant message content, if trades is non-empty, render each trade as a small confirmation pill:
      `"Executed {side} {quantity} {ticker}"` — green pill for buy, red pill for sell
    - After assistant message content, if watchlist_changes is non-empty: `"Watchlist: {action}ed {ticker}"` in blue pill

    Loading indicator: while loading=true, show a pulsing "Thinking..." text (or animated dots) in assistant bubble position.

    Input area: textarea (rows=2), full width. Send button with accent-purple background (`#753991`). Submit on Enter without Shift (Shift+Enter = newline). Input disabled while loading.

    Auto-scroll: after each message append, scroll the message container to the bottom (use a `div` ref and call `ref.current.scrollTop = ref.current.scrollHeight`).

    Panel height: full height of right column (set by parent layout). Message container: flex-1 with overflow-y: auto. Input area: fixed at bottom of panel.

    Export: `export function ChatPanel({ onTradeExecuted }: ChatPanelProps)`
