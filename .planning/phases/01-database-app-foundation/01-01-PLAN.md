                 quantity REAL, price REAL, executed_at TEXT
  portfolio_snapshots: id TEXT PK, user_id TEXT, total_value REAL,
                       recorded_at TEXT
  chat_messages: id TEXT PK, user_id TEXT, role TEXT, content TEXT,
                 actions TEXT, created_at TEXT

All user_id columns default to "default".
DB file path: db/finally.db (relative to project root, one level above backend/).

  <behavior>
    - get_db_path() returns Path("../db/finally.db") resolved relative to the init_db.py file location, so it resolves correctly regardless of cwd
    - init_db(db_path=None) uses get_db_path() if db_path is None
    - All 6 CREATE TABLE IF NOT EXISTS statements execute without error on a fresh DB
    - All 6 CREATE TABLE IF NOT EXISTS statements execute without error on an existing DB (idempotent)
    - After init, users_profile has exactly 1 row: id="default", cash_balance=10000.0
    - After init, watchlist has exactly 10 rows for the 10 default tickers with user_id="default"
    - Calling init_db() twice does not raise and does not create duplicate rows (INSERT OR IGNORE)
  </behavior>
  <action>
    Create backend/app/db/ directory with __init__.py and init_db.py.

    init_db.py exports two functions: get_db_path() -> Path and init_db(db_path: Path | None = None) -> None.

    get_db_path() computes the DB path as: Path(__file__).parent.parent.parent.parent / "db" / "finally.db".
    This resolves to {project_root}/db/finally.db regardless of the working directory.

    init_db() must:
    1. Ensure the parent directory of db_path exists (db_path.parent.mkdir(parents=True, exist_ok=True))
    2. Open a sqlite3 connection to db_path
    3. Execute CREATE TABLE IF NOT EXISTS for all 6 tables with exact column names from the schema above
    4. Use INSERT OR IGNORE for seed data to ensure idempotency
    5. Seed users_profile: INSERT OR IGNORE INTO users_profile (id, cash_balance, created_at) VALUES ("default", 10000.0, <iso_timestamp>)
    6. Seed watchlist: INSERT OR IGNORE INTO watchlist (id, user_id, ticker, added_at) for each of the 10 default tickers from seed_prices.SEED_PRICES keys; generate UUIDs with uuid.uuid4()
    7. Call conn.commit() and conn.close()

    Use stdlib only: sqlite3, uuid, datetime (no third-party deps needed).

    __init__.py must export: init_db, get_db_path.

    python-dotenv is NOT needed in this module — dotenv loading happens in main.py.
  </action>
  <verify>
    <automated>cd backend && uv run --extra dev pytest tests/db/test_init_db.py -v</automated>
  </verify>
  <done>
    init_db() creates all 6 tables with correct columns; seed rows inserted; idempotent on second call; all tests pass
  </done>
</task>
